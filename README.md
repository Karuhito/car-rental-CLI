# レンタカー管理シミュレーションCLIアプリ

## アプリ概要
レンタカー業者の管理業務と、利用者のレンタル操作の両方を再現するCLIアプリケーション。
業者側はレンタカー情報のCRUD管理を行い、利用者側は車の貸出・返却を行う。

## 作ろうと思った理由
図書館の貸出管理アプリでは面白くないため、ひねりを加えてレンタカーの貸出状況を管理できるアプリを作ろうと考えた。

## ターゲットユーザー
- レンタカーを利用したい個人（学生、営業職、家族連れなど）
- レンタカー業者の管理担当者（車両の貸出状況を管理したい）

## アプリのコンセプト
レンタカーの業者側の管理と利用者側の動きを再現したCLIアプリ

## 主要機能一覧

### 業者側
- 業者メニューへのアクセス制御（固定パスワードによる認証、MVP）
- レンタカー情報の記録
  - C: 車の新規登録
  - R: 車の一覧表示（状態・メーカーで絞り込み）
  - U: 車情報の更新（走行距離・使用履歴など）
  - D: 車の削除（廃車）
- 利用者情報の管理（一覧表示・削除）

### 利用者側
- 車を借りる操作（貸出）
- 車を返却する操作（返却）
- レンタル可能な車の一覧表示（メーカー絞り込み、車種ごとの並び替え）
- 新規ユーザー登録・ユーザー情報の更新

## 使用技術
- Java
- データ管理: CSV（DBは使用せず、`data/` 配下のCSVファイルで永続化）

## クラス構成（パッケージ構成）

```
src/
├── main/                   <-- 画面（CLI）とプログラムの起動を担当
│   ├── Main.java           // プログラムの起動（エントリーポイント）
│   ├── Menu.java           // トップメニューの画面制御
│   ├── EmployeeMenu.java   // 業者メニューの画面制御（固定パスワードによるアクセス制御）
│   └── UserMenu.java       // 利用者メニューの画面制御
│
├── model/                  <-- データの入れ物（状態・情報の保持）を担当
│   ├── Car.java            // 車クラス
│   ├── User.java           // 利用者（顧客）クラス
│   ├── CarStatus.java      // 車の状態を定義するENUM（待機中、貸出中、点検中）
│   ├── CarTransmission.java// 車がATなのかMTなのかを定義するENUM（AT, MT）
│   └── CarMaker.java       // 車のメーカーを定義するENUM（トヨタ、日産、ホンダ、スバル、その他）
│
├── service/                <-- データの加工や業務ルール（ロジック）を担当
│   ├── CarService.java     // 車のCRUD、および「貸出（年齢・免許チェック）/返却」の実行
│   └── UserService.java    // 利用者の登録、一覧表示、更新、削除の管理
│
└── util/                   <-- 共通で使う便利な補助機能を担当
    └── InputUtil.java      // キーボード入力（Scanner）の受付、数値・文字チェック
```

## 各クラスの役割

| クラス | 役割 |
|---|---|
| Main | プログラムの開始と全体制御 |
| Menu | メニュー表示 |
| EmployeeMenu | 業者メニュー（固定パスワードによるアクセス制御） |
| UserMenu | 利用者メニュー |
| Car | 車データの保持 |
| CarService | 車の情報のCRUD、車の貸出（未成年・免許チェック）・返却の処理 |
| User | 利用者データの保持 |
| UserService | 利用者のCRUD |
| InputUtil | 入力受付と入力チェック |

## データ設計

### Car（車）

| フィールド | 型 | 内容 |
|---|---|---|
| id | int | 車を判別するユニークなID |
| vehicleModel | String | 車種（ハイエース、プリウスなど） |
| color | String | 車の色 |
| maker | CarMaker（ENUM） | 車のメーカー（トヨタ、日産、ホンダ、スバル、その他） |
| status | CarStatus（ENUM） | 車の状態（待機中、貸出中、点検中） |
| cumulativeMileage | int | 累計走行距離（km） |
| currentUserId | Integer | 現在借りている利用者のID（貸出中以外はnull） |
| transmission | CarTransmission（ENUM） | AT / MT |

### User（利用者）

| フィールド | 型 | 内容 |
|---|---|---|
| id | int | 利用者を判別するユニークなID |
| name | String | 利用者の氏名 |
| age | int | 利用者の年齢（未成年の貸出制限に使用） |
| isATLimited | boolean | AT限定免許かどうか |

### データ保存方式
- DBは使用せず、`data/` 配下のCSVファイルでローカルデータ管理を行う（`data/cars.csv`, `data/users.csv`）
- 起動時にCSV全件を`List`に読み込み、メモリ上で操作 → 更新時にCSVへ書き戻す方式
- 詳細な設計判断は [docs/memo.md](docs/memo.md) を参照
